# OCR 错字兼容表

`ocr_text_fix.json` 用于兼容「游戏内/OCR 输出与项目里写的匹配文本不一致」的情况：
繁简混用、形近字、官方文案错字等。

## 格式

```json
{
  "鏡像冗余": "镜像冗余"
}
```

- **key**：OCR 实际可能输出的文本（错字）
- **value**：项目代码里使用的文本（正确字）

两者**长度必须相同**：补丁按字符位对齐，提取出「正确字符 → 错字字符」的映射，
再把这些错字作为可选项注入匹配文本。

上例会得到 `{"镜": ("鏡",)}`，于是所有匹配文本里的 `镜` 都会被展开成 `[鏡镜]`，
既能匹配「镜像冗余」也能匹配「鏡像冗余」。

需要双向容错时成对书写（例如项目里也可能照抄游戏文案写成 `鏡像冗余`）：

```json
{
  "鏡像冗余": "镜像冗余",
  "镜像冗余": "鏡像冗余"
}
```

## 生效范围

- 字符串匹配：`"镜像冗余"` → `["镜像冗余", "鏡像冗余"]`
- 正则匹配：仅替换字面量字符，转义序列（`\d`、`\.` 等）与 `[...]` 字符集内部结构
  不会被破坏，字符集内是**追加**错字而非重建
- 列表匹配：逐元素处理并展平

任何正则编译失败都会回退到原始匹配文本，不会打断任务。

## 生效时机

`src/config.py` 末尾调用 `install_ocr_text_fix_patch()`，patch 了
`ok.task.task.OCR.fix_match_regex`（在既有 i18n 翻译逻辑之后执行）。
新增/修改本文件后重启程序即可，无需改代码。

实现见 `src/patches/ocr_text_fix_patch.py`（移植自 ok-end-field）。
