# 周常任务

## 概述

自动完成每周例行挑战任务，从游戏主界面开始。支持各子任务独立开关。

---

## 子任务

### 首领挑战

> 检查单：「战役推进 → 模拟作战 → 首领挑战」可用。

自动进入首领挑战关卡，先切到「常规挑战」页签，快速完成挑战并领取奖励。「歧路挑战」页签（指挥官 50 级解锁）没有自律，不自动打。

选项：『⭐首领挑战』

### 峰值推定

> 检查单：「战役推进 → 模拟作战 → 峰值推定」可用。

自动进入峰值推定界面，先后完成：
1. **常规峰值**：领取周期报酬
2. **极限峰值**：依次挑战各等级关卡

支持自动识别并领取周期报酬奖励。

- 进页面后先认右下角「常规峰值 / 极限峰值」标签；认不出时只按一次 ESC（关掉可能盖着的弹窗）再看，还认不出就截图（peak_page_unknown）回主页跳过，不再连按 ESC。
  实录 2026-11-03：新一期第一次进来没认出「常规峰值」，原流程连按 6 次 ESC 退过主页开出「个人信息」，后面的扩编实练找不到入口，整个周常报错停掉。
- 极限峰值是部署关：新一期部署界面是空的（部署人形 0/5），进部署界面后按全局「阵容与助战」的「峰值推定编队」（留空沿用默认编队）切整备室编队并补满，再开战。
- 极限峰值某个子群打输了（实录 2026-11-03：新一期子群1 推荐 60 级、敌人 70 级）就不再打后面更难的子群，回主页接着下一项，不让整个周常报错停掉。

选项：『⭐峰值推定』

### 扩编实练

> 检查单：「战役推进 → 模拟作战 → 扩编实练」可用。

自动进入扩编实练界面，根据剩余体力情况判断是否挑战特殊增强关卡。特殊增强是部署关：进部署界面后按全局「阵容与助战」的「扩编实练编队」（留空沿用默认编队）切整备室编队并补满，再开战；该关没有好友助战。

选项：『⭐扩编实练』（默认开）

---

## 运行顺序

```
首领挑战 → 峰值推定 → 扩编实练
```

各子任务按上述顺序依次执行，完成后自动输出"周常完成！"通知。每项开始前先回主页再点「战役推进 → 模拟作战」；右上角找不到「战役推进」时再回一次主页重试（上一项把页面退到了「个人信息」等页面也能接着跑）。
