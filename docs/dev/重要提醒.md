# 重要提醒维护指南

`src/notices/__init__.py` 中的 `NOTICES` 是随版本发布的本地静态提醒列表，启动时无需网络请求。

- `id`：稳定且唯一的已读状态标识；**不能复用旧 ID**，否则已读用户可能看不到新提醒。
- `title`：标签页及启动弹窗中的标题；`task`：受影响的任务；`solution`：临时解决方法或需调整的配置。
- `url`：详情公告或 issue 的真实链接；`active`：是否生效，设为 `False` 可让旧提醒不再显示或弹出，同时保留旧 ID。

添加提醒时，在两个 `i18n/*/LC_MESSAGES/ok.po` 中加入 `title`、`task`、`solution` 的对应 `msgid` 和译文，再编译 `ok.mo`。新增界面文本也须翻译。已读 ID 保存在跨账号共享的 `configs/notice_state.json` 中，用户点击“不再提示”后写入；关闭或查看链接不会标记已读。配置中的「喝水」原值不会自动迁移。
