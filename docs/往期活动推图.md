# 往期活动推图

## 概述

把「作战 → 往期活动 → 活动剧情」里的往期活动按顺序推完。每个活动里的关卡地图、关卡面板和主线一样，
所以每关怎么推（整章扫到不动点、对勾判断、挑战 / 观看、英雄难度以外的阵容整理）都直接沿用 [清图任务](清图任务.md)，
这里只换掉「章节」那一层的导航（代码 `src/tasks/EventMapTask.py`）。

阵容和主线推图共用「推图」的编队和助战设置。

---

## 工作流程

1. 启动时：
   - 停在某个活动的关卡地图上 → 直接推这个活动；
   - 停在主页 / 作战的任意页签 / 往期活动列表 → 进「往期活动 → 活动剧情」，把列表拖回最左边，
     从左往右找**第一个完成度不到 100% 的活动**点进去（跳过开场剧情）。
2. 活动地图右下有「剧情 / 物资」两个页签，各是一张关卡地图（物资是 MF-1-x 这类推荐等级更高的关），两边都算完成度：
   每一轮先切「剧情」整图推完，再切「物资」推完。哪个页签选中看按钮是不是实心彩色（同普通 / 困难按钮）；「物资」点两次还没变成选中 = 还没解锁（剧情没推到），这一轮先跳过。
   活动地图没有普通 / 困难；部分活动有英雄难度，推图只推剧情难度。
   每个页签推完：左下角是「可领取」就点开收集数弹窗，把能领的档位都领掉（同推图的「领取章节奖励」），
   还有「未完成」的档位会通知出来——多半是漏了关卡或有关卡没三星通关。
   「剧情」页签左边有「心智回溯 xx%」卡片（第 8 期起）且没到 100%：点开，列表里「可观看」的一条条播放
   （进剧情点「全部跳过」也算看完，弹「获得道具」30 抽卡资源），后面的「观看前置剧情以解锁」看完前一条才开，一直往下翻到底。
3. 推完一轮（扫到不动点）后按 ESC 回列表，读这个活动卡片上的「完成度」：
   - 100% → 这个活动推完；
   - 不到 100% → 点回去再推一轮；连续两轮一关都没推还不到 100%（剩下的是挑战目标没拿满或未解锁），放下这个活动。
4. 「推完继续下一个活动」开着就回列表找下一个完成度不到 100% 的活动，这次推过 / 放下的不再回头选。
5. 都满了以后再从左往右扫一遍列表，卡片右上角带橙色「!」（奖励没领完）的活动逐个进去，
   每个页签领章节奖励、看心智回溯；每个活动这次只进一次（英雄难度之类领不掉的「!」不会来回进）。

列表上的活动名按位置配对：「完成度 xx%」正上方的那行字。活动名 OCR 常错字（「狂想四重奏」读成「狂想四重秦」），
按相似度认；「·上篇 / ·下篇」只差一个字，必须当成两个活动。

## 配置

| 选项 | 默认 | 说明 |
|---|---|---|
| 普通OCR / 除杂色OCR1 / 除杂色OCR2 | 开 | 同推图，识别关卡名的三种预处理 |
| 战斗内点击自动 | 关 | 同推图 |
| 推完继续下一个活动 | 开 | 关掉就只推当前（或第一个没推完的）活动 |
| 领取章节奖励 | 开 | 每个页签推完领左下角的收集数奖励，「未完成」的档位通知出来 |
| 看心智回溯 | 开 | 把心智回溯里能看的剧情跳过看完领抽卡资源；推完后再去领列表上带「!」的活动 |

## 实录

**2026-10-22 首次实测**（2560x1440，远程桌面会话）：往期活动共 18 个，全部 0%。从列表进「01 狂想四重奏」，
MA-1-1 挑战（第一次进部署界面按「推图」设置整理阵容，借到 6 椎威玛西娜）→ MS-1-1 剧情点观看 → MB-1-1 挑战，
关卡卡片样式、面板、继续前进都和主线一致。剧情页签全推完（卡片全有对勾）后列表上完成度 75%，
连续两轮推不动后放下、进了「02 拂晓的回响」（切换正常）。查下来剩下的 25% 是「物资」页签的 MF-1-1～1-x，
所以改成两个页签都推；改完重跑，狂想四重奏推到 100% 后自动进了拂晓的回响。
切页签时如果关卡面板还在收起动画里，点击会不生效（实录：点了「剧情」还停在物资图上），地图没变就再点一次。同一轮还发现活动里未解锁的提示是「需要完成前置关卡」（主线是「完成前置关卡解锁」），已两种都认。

**2026-10-22 第二个活动**：拂晓的回响剧情页签推完后「物资」解锁（ZF-1-x），两个页签推完完成度 100%，自动进「03 密米尔的返演·上篇」。
这个活动的卡片是白底样式，右上角对勾没认出来，每关都点开面板靠「没有特殊奖励」判断已通关，结果对但慢一些。

**2026-10-22 第三个活动**：密米尔的返演·上篇剧情推完、点「物资」没切过去（还锁着），但点完地图视野挪了、关卡名变了，
旧逻辑当成切过去了，把剧情图又扫了一遍。改成看按钮颜色认选中的页签（选中 0.77 / 没选中 0）。
同一个活动还发现：地图顶上的小字活动名被 OCR 拆成「密米尔的返演」「·上篇」两个框，只取第一个会和下篇混淆（推完把下篇也当成推过）。
现在同一行的框按 x 拼起来，读到列表后改用列表上的名字。改完重跑：物资页签按颜色确认切过去、推完，上篇 100%，自动进了下篇。
这个活动的通关标记是绿色对勾（狂想四重奏是橙色），也认不出，靠点面板判断。

**2026-10-22 第四个活动**：密米尔的返演·下篇 PS-1-7 的剧情后面有个特殊演出页「掩码列表 / 演算完成」，只有一个「终止覆写」按钮，
剧情的「跳过」点不掉，卡了两分钟。我停了任务手动点了「终止覆写」，后面是「终止码演算」文字页（底部「点击空白处继续」OCR 读不到），
点空白处后回到普通剧情。已写进 `skip_dialogs`：看到「终止覆写」就点，看到「终止码演算 / 点击空白处继续」就点屏幕中间。

**2026-10-22 第六个活动**：纪念日礼赞的页签是另一套配色，选中的「剧情」是灰绿色（饱和度只有 70 左右），
按难度按钮的门槛（S>90）认不出，被当成「剧情点了没切过去」跳过，直接推了物资。改成页签用 S>50 算实心：
选中的按钮各活动都在 0.73 以上，没选中的仍是 0。

**2026-10-22 第九个活动**：沉没夜潮选中的「剧情」是蓝灰色，饱和度只有 26，放宽到 S>50 也认不出，又先推了物资（这个活动左边还多一个「难度」按钮）。
看颜色靠不住，改成两个页签都在时比亮度：选中的按钮各活动都在 V 129～177，没选中的 74～100，亮出 20 以上就算选中；只看到一个页签时才看是不是实心彩色。

**2026-10-22 第十个活动**：镜茧与囚蝶推完回列表，日志「列表上没找到活动「镜茧与囚蝶」」，没读到完成度就去了下一个。
看列表截图：拖列表是 60ms 划完马上松手，会甩出惯性，平时挪两张卡片，这次从「逃离赛博格…烟火迎春归」一下挪到「…乐园 / 沉没夜潮」，
中间几张被整段跳过（顺带「…乐园」这个没推的活动也没被选中）。改成拖到位停 0.5 秒再松手；
拖完和拖之前一张卡片都对不上就判定挪过头，往回拖半程补看。
改完后拖一次只挪一张卡片，在第 5 张发现了之前每次都被甩过去的「驻足之地」（完成度 0%），说明前几轮其实一直在漏活动。
一次一张、一屏 4 张，18 个活动要拖 14 次，原来最多拖 12 次不够，放宽到 30 次。

**2026-10-22 驻足之地卡在 79%**：剧情页签 DA-1-7～1-9 一直「需要完成前置关卡」，剧情、物资各扫两轮都推不动。
截图上前置关是剧情关 DS-1-1：它是「当前」关，卡片浅绿底、深色字、带声波纹样，没有通关对勾，但三种 OCR（原图、两种白字过滤）
整屏大多检测不到它的名字（前两轮都没读到，第三轮碰巧读到一次才推过去；再读不到就会按「连续两轮推不动」放弃这个活动）。
单独把这张卡裁出来、按深色字二值化就能稳定读到「DS-1-1」。
已写进 `ClearMapTask`（主线推图也受益），见下面「瑞骋迎春至」一条的切块补读。

**2026-10-22 王牌配送员**：停在活动地图上启动时读顶上的活动名，这个活动在名字上面还有一行装饰字「SAKURA」，
旧逻辑只取最上面一行，读成空（日志「停在活动「?」的地图上」），推完就没法回列表核对完成度。改成从上往下取第一行有中文的。

**2026-10-22 打完回地图的加载页把推图停了（两次）**：08:49 和 09:38 打完战斗点确认后，游戏停在「资源加载中 39%」加载页 30 多秒，
日志先是 WGC「no frame for 10 sec」，然后「跳过剧情超时! 当前在未知页面」，任务停了，两次都是我手动重启。
skip_dialogs 本来就会在加载页顺延超时，但每次只顺延到「现在 + 5 秒」；加载页画面不动，WGC 不出新帧，循环末尾的 next_frame 一卡 10 多秒，
回到循环判断时早过了期限。顺延改成至少 30 秒（`LOADING_EXTEND`，总上限仍是 loading_grace），主线推图、日常同样受益。

**2026-10-22 瑞骋迎春至**：未解锁的关是暗红底灰字，视野滚到全是未解锁关的一段时整屏一张卡都读不到，
任务以为不在地图上，走了「回地图」的恢复流程。试下来问题不在颜色：整屏 OCR 会把 2560 宽的画面缩小再检测，低对比小字检测不到；
单独裁出卡片，原图就能读到「LA-1-5」。驻足之地的 DS-1-1 也是同一个原因。
改成切块补读（`scan_tiles`）：画面切成 3x2 块、相邻块重叠 1/4，分别 OCR，补出整屏没读到的关卡（每屏约 1 秒）。
两种时候补读：整屏一张卡都没读到；一遍扫完一关没推、还有未解锁的关（这一遍每屏都补读）。
上一版「只补读卡片之间的空档、按深色字二值化」处理不了满屏都读不到的情况，已换掉。

**2026-10-22 10:34 列表没扫到底就收工**：日志「没有完成度不到 100% 的往期活动了」，但素银匿信（95%）、瑞骋迎春至、月下安魂曲还没推。
