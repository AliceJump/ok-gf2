# Weekly

## Overview

Completes the weekly challenges, starting from the game's main screen. Each step can be switched on
or off on its own.

Game terms below use the wording from the Global / Steam client. See
[../glossary.md](../glossary.md) for the full mapping.

---

## Steps

### Boss Fight

> Checklist: Campaign -> Combat Simulations -> Boss Fight is available.

Enters Boss Fight, clears it, and claims the rewards.

Options: `⭐Boss Fight`

### Peak Value Assessment

> Checklist: Campaign -> Combat Simulations -> Peak Value Assessment is available.

Opens Peak Value Assessment and completes it in two passes:

1. **Standard**: claims the periodic rewards
2. **Extreme**: works through each difficulty tier in order

Periodic rewards are detected and claimed automatically.

Options: `⭐Peak Value Assessment`

### Expansion Drills

> Checklist: Campaign -> Combat Simulations -> Expansion Drills is available.

Opens Expansion Drills and decides whether to attempt the special enhanced stage based on how much
Intelligence Puzzle you have left.

Options: `⭐Expansion Drills`

---

## Run order

```
Boss Fight -> Peak Value Assessment -> Expansion Drills
```

The steps run in that order, and a "Weekly complete!" notification is sent when they finish.

> These three modes are also reachable from Regular Commissions, which links out to the same stages.
